## 1. ゲーム概要

会員登録なしで始められる(端末単位のゲストアカウント)、リアルタイム対戦のモンスター収集ゲーム。
本家ポケモンの対戦ルールから、天候・フィールド・持ち物・特性・技の追加効果などを外した小さなルールで遊ぶ。

### コアループ

```
① スカウトでパチモンを集める(ジェムを使う)
      ↓
② 育成する(技の付け替え、ステータスポイントの割り振り。割り振りにはジェムで交換したチケットを使う)
      ↓
③ パーティを編成する(最大6体)
      ↓
④ マッチングに参加し、対戦相手と組む
      ↓
⑤ パーティを見せ合って3体を選び、リアルタイムで対戦する
      ↓
① へ戻る(勝つとジェムがもらえる。ジェムはスカウトと、ショップでの育成チケットの購入に使う)
```

チャットはこのループとは別の、全プレイヤー共通の1つのチャンネル。

### 用語

| 用語 | 意味 |
|---|---|
| パチモン | 集めて戦わせるモンスター。種族ごとにタイプ・能力・覚えられる技が決まっている |
| 個体 | プレイヤーが所持している1体1体のパチモン。同じ種族を複数持てる |
| ジェム | スカウトとショップで使う通貨。対戦に勝つと増える |
| スカウト | ジェムを使ってパチモンを入手する抽選(ガチャ) |
| パーティ | 対戦に連れていく最大6体 |
| 育成 | 個体の技を付け替えたり、ステータスポイントを割り振ったりして、対戦向けに調整すること |
| ステータスポイント | 個体ごとに持つ64ポイント。6つの能力に自由に割り振って能力を上げる |
| 育成チケット | ショップでジェムと交換するアイテム。1枚で1体のステータスポイントの割り振りを変更できる |
| ショップ | ジェムでアイテムを購入する場所 |
| 選出 | 対戦の直前に、パーティから実際に戦わせる3体を選ぶこと |

## 2. 遊びの流れ

```
起動 ─→ タイトル(自動でゲスト認証。初回はプレイヤーを作成)
          ↓
        ホーム ─┬─ パーティ編成
                ├─ スカウト
                ├─ ショップ(追加予定)
                ├─ 対戦 ─→ マッチング待ち ─→ 選出 ─→ 対戦 ─→ 結果 ─→ ホーム
                └─ 育成(技の付け替えは未実装、ステータスポイントの割り振りは追加予定)
```

- ホームには所持ジェムを表示する
- 開発用に、ホームにジェムを付与するボタンがある(正式な機能ではない)

## 3. アカウント

- 会員登録(メールアドレス・パスワード等)は無い。初回起動時に端末ごとのゲストアカウントを自動で作る
- 別の端末への引き継ぎは無い
- 初回はプレイヤーを作成し、次のものを受け取る
  - スターターパーティ: 全プレイヤー共通の固定6体(レア度Cの6体)。受け取った時点でパーティに編成済みで、すぐに対戦できる
  - ジェム300(スカウト2回分)
- ニックネームを決める画面(未実装)

## 4. パチモン

### 種族

- 36種(レア度S: 18種、A・B・C: 各6種)
- タイプは18種類(ノーマル・ほのお・みず・でんき・くさ・こおり・かくとう・どく・じめん・ひこう・エスパー・むし・いわ・
  ゴースト・ドラゴン・あく・はがね・フェアリー)。1体につき1つか2つ
- 能力は6種類(HP・こうげき・ぼうぎょ・とくこう・とくぼう・すばやさ)。種族ごとの基本値(種族値)で決まる

### 個体

- レベルは全員50で固定(経験値で成長する要素は無い)
- 個体値(同じ種族での能力のばらつき)は無い
- ステータスポイント64を能力に割り振れる(「5.3 ステータスポイントの割り振り」参照)。割り振る機能は追加予定で、現状は全員0

### 技

- 1体が覚えられる技は4つまで
- 種族ごとに「覚えられる技の候補」が決まっていて、入手した時点では候補のうち初期技4つを覚えている
  (現状の候補は各種族5つ: 専用技・共通のノーマル技・タイプ技2つ・付け替え用の技1つ)
- 技には、タイプ、物理/特殊の分類、威力、命中率、PP(使える回数)がある
- 技の追加効果(状態異常・能力変化など)は無い

## 5. パーティ編成・育成

### 5.1 パーティ編成

- 所持している個体から1〜6体を選んで編成する
- 同じ個体を2つの枠に入れることはできない。同じ種族の別の個体なら何体でも入れられる
- パーティが0体だと対戦に参加できない

### 5.2 技の付け替え(未実装)

- 個体が覚えている4つの技のうち1つを、その種族の技の候補の中から選んで入れ替える
- 何度でも無料で付け替えられる
- 仕様とAPIはあるが、画面が無い

### 5.3 ステータスポイントの割り振り(追加予定)

- 個体ごとにステータスポイントを64持ち、6つの能力(HP・こうげき・ぼうぎょ・とくこう・とくぼう・すばやさ)に自由に割り振る
- 割り振ると、その能力の実際の値が上がる。入手したときは全能力0(割り振っていない状態)
- 割り振りを変更するには育成チケットを1枚使う。1枚で1体の割り振りを1回変更できる
- 育成チケットはショップでジェムと交換して手に入れる(「7. ショップ」参照)
- 今の実装にあるのは個体ごとの割り振りの入れ物(全能力0)だけで、割り振り・チケット・交換のAPIと画面は無い
- 未確定
  - 1つの能力に割り振れる上限の有無
  - 1ポイントで能力がどれだけ上がるか(ステータスの計算式への反映の仕方)
  - 初めて割り振るときにもチケットが要るか

## 6. スカウト

本家ポケモンの「紹介(候補10体から1体を選ぶ)」をもとにした抽選。

- 開催中のスカウトから1つ選び、ジェムを払って「紹介」を受ける(現状は常設の「レギュラースカウト」のみ、1回150ジェム)
- 紹介ごとに候補10体が提示され、その中から1体を選んで入手する
  - 選ばなかった9体は消える
  - 候補を選ぶまでスカウト画面から戻れない(選ばずにアプリを終了すると、その紹介は選べなくなり、ジェムも戻らない)
- 候補10体は1体ずつ次の確率でレア度を決め、そのレア度の種族から等確率で選ぶ

| レア度 | 確率 |
|---|---|
| S | 3% |
| A | 12% |
| B | 35% |
| C | 50% |

- 入手した個体は初期技4つを覚えている
- 排出率はクライアントに渡さない(表示もしない)

## 7. ショップ(追加予定)

ジェムを使ってアイテムを購入する。今のところ商品は育成チケットだけ。

- 商品を選び、表示された値段のジェムを払って購入する。ジェムが足りなければ購入できない
- 購入したアイテムは所持品として持ち、使うと減る(育成チケットは割り振りの変更で1枚使う)
- 所持しているアイテムの数を確認できる
- 未確定
  - 育成チケットの値段(何ジェムで1枚か)
  - まとめ買い(一度に複数枚)の可否
  - 購入数の上限の有無(1日あたり・所持数)
  - ショップの商品を運用中に入れ替えられるようにするか(マスタで持つか、固定にするか)

## 8. 対戦

1対1で、パーティから選んだ3体どうしで戦う。

### 8.1 マッチング

- 対戦ボタンでマッチングの待機列に入り、もう1人が来たら対戦相手が決まる(先着順。強さによる組み分けは無い)
- 待っている間はキャンセルできる

### 8.2 選出

- 対戦相手が決まると選出画面になり、お互いのパーティ(どのパチモンか)を見せ合う。相手の技や能力の振り方は見えない
- 自分のパーティから3体を選ぶ(パーティが3体未満ならその体数)。選んだ順番がそのまま並びになり、1番目が最初に場に出る
- 選んだパチモンをタップすると、画面中央にその能力と技を表示する
- 「けってい」を押すと、相手が選び終わるまで選出画面のまま待つ。両者がそろったら対戦が始まる
- 制限時間は2分。時間内に選ばなかった側の負け(両者とも選ばなかった場合は勝者なし)

### 8.3 ターンの進み方

- 毎ターン、お互いに「技を使う」か「控えと交代する」を1つ選ぶ。制限時間は30秒
- 時間内に選ばなかった場合、そのターンは何もしない(相手の行動だけが行われる)
- 両者の行動がそろったら、次の順番で行動する
  1. 交代は技より先
  2. 技どうしは、すばやさが高い方が先。同じならランダム(先制技は無い)
- 行動の結果は、行動した順に1文ずつメッセージで流れ、HPゲージもそれに合わせて減る

### 8.4 技とダメージ

- 技を選んだ時点でPPを1使う(外れても使う)。PPが0の技は選べない
- 命中率に従って当たり外れが決まる
- ダメージは本家の基本式を使う。攻撃側のこうげき(物理)/とくこう(特殊)と、防御側のぼうぎょ/とくぼうで決まり、
  さらに次の倍率がかかる

| 倍率 | 内容 |
|---|---|
| タイプ一致 | 技のタイプが使うパチモンのタイプと同じなら1.5倍 |
| タイプ相性 | 0倍(効果なし)・0.5倍(いまひとつ)・1倍・2倍(ばつぐん)。相手が2タイプなら2回かけ合わせる |
| 急所 | 1/16の確率で1.5倍 |
| 乱数 | 0.85〜1.00倍 |

### 8.5 瀕死と交代

- HPが0になると瀕死になり、そのパチモンは行動できない
- 自分のパチモンが瀕死になったら、次のターンは「強制交代ターン」になり、控えから次に出すパチモンを選ぶ。
  この間、相手は待つ(何も選べない)
- 強制交代の制限時間は30秒。時間内に選ばなかった場合は負け

### 8.6 相手の情報の見え方

- 相手のパチモンは、場に出るまでどの3体を選んだか分からない(枠の数と、何体倒れたかは分かる)
- 相手のHPは%で表示する(実数は分からない)

### 8.7 勝敗

| 決着の仕方 | 勝者 |
|---|---|
| 相手の選出3体をすべて倒した | 倒した側 |
| 降参した | 相手 |
| 選出の制限時間内に選ばなかった | 相手(両者なら勝者なし) |
| 強制交代の制限時間内に交代しなかった | 相手 |
| 3ターン続けて何もしなかった(放置) | 相手(両者同時なら勝者なし) |
| 接続が切れて60秒以内に戻らなかった | 相手 |

- 接続が切れている間(最大60秒)は、お互いに行動できない。60秒以内に戻れば続きから再開する
  (サーバーは対応済みだが、クライアントが自動でつなぎ直す処理は未実装。現状は一度切れると戻れない)
- 勝つとジェム50をもらえる。負けたとき・勝者なしのときはもらえない
- 対戦の結果と各ターンの行動は記録される

## 9. ジェム

| 増減 | きっかけ | 量 |
|---|---|---|
| 増える | プレイヤー作成時 | 300 |
| 増える | 対戦の勝利 | 50 |
| 増える | 開発用の付与ボタン(正式な機能ではない) | 450 |
| 減る | スカウトの紹介1回 | 150 |
| 減る | ショップでの購入(育成チケット1枚)(追加予定) | 未確定 |

- 所持数の増減はすべてサーバーが決める
- 報酬額とスカウトの値段のバランスは仮の値

## 10. チャット

- 全プレイヤー共通の1つのチャンネルにメッセージを送り、一覧を読む(新しい順)
- 相手からのメッセージは、定期的に取り直して表示する想定(リアルタイムの通知は無い)
- 仕様とAPIはあるが、画面は未実装

## 11. 対象外にしたもの・今後の検討

小さなルールで遊べるようにするため、次のものは入れていない。

- 対戦: 天候・フィールド・持ち物・特性・性格・技の追加効果(状態異常・能力変化)・先制技・急所率の変化・命中/回避の変化
- 育成: レベルアップ、個体値
- スカウト: 期間限定スカウトの運用、色違い、紹介の取り直し
- 報酬: デイリーミッション・ログインボーナス、負けたときの参加賞
- 不正対策(複数アカウントでのわざと負ける対戦など)

今後の検討:

- ステータスポイントの割り振り・育成チケット・ショップの追加
- 技の付け替え・チャット・ニックネーム入力の画面
- 育成チケットとショップの細部(「5.3 ステータスポイントの割り振り」「7. ショップ」の未確定事項)
- 報酬額、スカウトと育成チケットの値段のバランス調整
