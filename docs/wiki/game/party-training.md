# パーティ編成・育成

## パーティ編成

- 所持している個体から1〜6体を選んで編成する
- 同じ個体を2つの枠に入れることはできない。同じ種族の別の個体なら何体でも入れられる
- パーティが0体だと対戦に参加できない
- 編成画面で個体を選ぶと、その能力と覚えている技を確かめられる

## 技の付け替え(画面は未実装)

- 個体が覚えている4つの技のうち1つを、その種族の技の候補の中から選んで入れ替える
- 付け替えるには育成チケットを1枚使う(チケットは追加予定)
- いまあるのは付け替えの API だけで、チケットの消費と画面は無い

## ステータスポイントの割り振り(追加予定)

- 個体ごとにステータスポイントを64持ち、6つの能力(HP・こうげき・ぼうぎょ・とくこう・とくぼう・すばやさ)に自由に割り振る
- 1つの能力に割り振れる上限は無い(64ポイントを1つの能力に全部入れてもよい)
- 割り振ったポイントは、種族値から計算した能力の値にそのまま足す(ポケモンチャンピオンズ準拠)。入手したときは全能力0
- 割り振りを変更するには育成チケットを1枚使う。1枚で1体の割り振りを1回変更できる
- 育成チケットはショップでジェムと交換して手に入れる([ショップ](shop.md))
- いまの実装にあるのは、個体ごとの割り振りの入れ物(全能力0)だけ。割り振り・チケット・交換の API と画面は無い
- 能力の計算式は、いまは本家の努力値の式(`floor(努力値 / 4)`)のままになっている([バトルの計算](../battle-server/battle-core.md))

未確定のこと(初めて割り振るときにもチケットが要るか等)は [未確定・保留](../open-questions.md)。
